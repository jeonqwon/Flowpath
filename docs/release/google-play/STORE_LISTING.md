## App name

## Short description

Plan tasks into your day with local-first scheduling, reminders, and recurring routines.

## Full description

OpenReclaim helps you turn a list of tasks into a day you can actually follow.

Create tasks with a due date, duration, preferred work period, and repeat rules. OpenReclaim places them into your available schedule, keeps meal and rest periods visible, and lets you reschedule or follow up when priorities change.

Features in the current Android release:

- day-based task timeline
- recurring daily and weekly tasks
- reminders and follow-ups
- productive periods and life periods
- planner month view with task density dots
- local-first storage on device

Designed for people who want:

- a clearer daily plan
- recurring routines that stay visible
- lightweight reminder support without a heavy setup flow
- a schedule that reacts when tasks move

Current release notes:

- no account required
- no cloud sync
- no external calendar connection in this version
