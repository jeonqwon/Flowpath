# Onboarding & Tutorials

## US-ON-01: First-time sleep setup
**As a** new user  
**I want** to be guided through setting up my sleep schedule  
**So that** the app can protect my sleep time from the start  

### Acceptance Criteria
- On first launch, prompts user to set up sleep
- Interactive tutorial highlights key UI elements
- "X of 7 days configured" progress shown in banner
- Can skip or dismiss the tutorial

## US-ON-02: Task creation tutorial
**As a** new user  
**I want** a guided walkthrough of creating my first task  
**So that** I understand how task scheduling works  

### Acceptance Criteria
- Tutorial triggers after sleep setup is complete
- Highlights: title field, duration, priority, save button
- Explains what each option does
- Can be skipped

## US-ON-03: Sleep day selection tutorial
**As a** new user  
**I want** to understand how to select days for my weekly sleep  
**So that** I can configure my sleep correctly  

### Acceptance Criteria
- Tutorial cutout highlights the day-of-week toggles
- Explains that at least one day must be selected
- Shows the next step or dismiss option
