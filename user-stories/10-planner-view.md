# Planner View

## US-PL-01: See all tasks in a grid
**As a** user  
**I want** to view my tasks in a planner/grid layout  
**So that** I can get a different perspective on my schedule  

### Acceptance Criteria
- Planner tab shows tasks in a grid format
- Tasks are organized by day or week
- Tapping a task opens its detail

## US-PL-02: See completed task history
**As a** user  
**I want** to view my completed tasks  
**So that** I can review what I've accomplished  

### Acceptance Criteria
- Completed tasks show in the planner view
- Each card shows title and completion date/time
- History respects the retention period setting

## US-PL-03: Manual schedule rebuild
**As a** user  
**I want** to trigger a full reschedule of all my tasks  
**So that** I can reorganize after making many changes  

### Acceptance Criteria
- Rebuild button or option available
- All flexible tasks are rescheduled from scratch
- Priority ordering is respected
- Progress indicator during rebuild (saving state)
